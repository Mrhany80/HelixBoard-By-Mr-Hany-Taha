How to install

  1. Click Download for Windows and open the file when it finishes.
  2. If Windows shows “Windows protected your PC”, click More info → Run anyway. (The app is not code-signed yet.)
  3. Open HelixBoard from the Start menu or the desktop shortcut.
Already installed? You don’t need to download again — HelixBoard offers Update now by itself when a new version is ready (or Page tab → Check for updates).
