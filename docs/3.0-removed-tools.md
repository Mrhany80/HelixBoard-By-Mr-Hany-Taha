# HelixBoard 3.0 — what was removed, what stays

Tools in the tabs: **368 → 304**. Source modules: 44 → 30. Web app file: 7,586 KB → 6,990 KB. App code: 1.60 MB → 1.02 MB.
The full 2.8 version is kept on the branch `archive/full-2.8`.

## Removed
| Tool or feature | Module | Why |
|---|---|---|
| Live class on phones (Draw it, polls, word cloud, short answer, photo, sticky wall, random pick, end session) | liveclass.js, desktop/live.js | Needs a phone server, Wi-Fi and firewall rules; largest source of network faults |
| Write on my board, class link, shared files | classlink.js, desktop/classlink.js, tunnel.js | Same server; sent the board to phones during writing |
| Phone quiz game | studio.js (phone quiz) | Depends on the phone server |
| Tests from worksheets, test dashboard, bubble-sheet exam | quizparse.js, quizimport.js, quizbuilder.js, testdash.js, sheetexam.js, desktop/testgrade.js | Exam platform, not a whiteboard tool |
| Reports, Class XP, Redemption quiz | reports.js, xp.js | Depend on phone results |
| Paper answer cards (webcam) | cards.js | Depends on reports and the camera |
| Video lessons | videolesson.js | Depends on live class |
| Collaborate tab: ten group structures, groups on the board, cluster frame, dot vote | collab.js | Second timer system; little use on a science board |
| Record lesson audio, play recordings, find/outline/tags, export notes, date stamp | notes2.js | Audio recording ran beside the ink |
| Record lesson video, Replay | io.js | Screen recording while writing |
| Ink → text, Photo → text | recog.js | Download 64 MB and 10 MB models on first use; blocked on school networks |
| Homework files (.hbhw, .hbres), My homework | studio.js | Student-side workflow |
| Study tab: practice quiz button, my mistakes, focus timer, brain dump, explain it simply, exam planner, my progress, duplicates of Teach buttons | studio.js | Student self-study, not teaching on the board |
| Water reminder (10 buttons) | water.js | Not a teaching tool; ran two timers all lesson |
| Question button on slides | deck.js | Depends on live class |
| Timer presets 1, 2, 3 and 15 min | ui.js | Board timer sets any time; 5 and 10 min stay |

## Bugs found and fixed
| Bug | Severity | Fix |
|---|---|---|
| Writing falls behind on a full board (whole page redrawn after every stroke) | P0 | Finished stroke painted straight onto the board |
| Pen freezes just after a pause (board and all pictures saved 800 ms after each change) | P0 | Save waits for a pause, runs when idle, writes pictures only when they change |
| A stroke written just before closing the app could be lost (save was only on a timer) | P1 | Save at once on leaving or closing |
| Concept-map code scanned every object for every pen sample, with any tool | P1 | Runs only with the Select tool |
| Minimap, page tabs, slide thumbnails and button states refreshed in the middle of writing | P1 | They wait until the pen has rested 1.2 s |
| Panels over the board blurred their backdrop; the title glow animated for ever | P1 | No blur on panels over the board; glow is static |
| Minimap threw "canvas with a width or height of 0" when a page had no size yet | P2 | Guarded |
| Magnifier code measured the layout on every pointer move even when off | P2 | Runs only while the magnifier is on |

No bug list was supplied, so the sweep looked for errors only: every tool button tapped with touch at 3840x2160 and 1366x768
(382 taps each) and in the Windows app shell (384 clicks): 0 errors, 0 modules failing at start.
